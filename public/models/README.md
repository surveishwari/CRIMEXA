# Mixamo character models (optional)

Place exported GLB files here for higher-quality characters:

- `idle.glb` — Mixamo "Idle" on X Bot or Y Bot
- `walk.glb` — Walking
- `fall.glb` — Dying
- `run.glb` — Running
- `punch.glb` — Punch
- `pickup.glb` — Pick Up
- `defeated.glb` — Defeated

Export settings: **GLB**, 30 FPS, With Skin.

If these files are missing, the app uses the Three.js Soldier demo model from the CDN automatically.

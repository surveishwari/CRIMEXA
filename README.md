# 🔍 CRIMEXA – AI Crime Scene Reconstruction & Evidence Mapping

## Overview

CRIMEXA is an AI-powered forensic intelligence platform designed to assist investigators in crime scene analysis, evidence mapping, and crime prediction. The system combines Computer Vision, Machine Learning, Full Stack Development, and Immersive Web Technologies to reconstruct crime scenes and generate actionable forensic insights.

The platform enables investigators to upload crime scene images, detect forensic evidence using AI models, visualize incidents in interactive 3D environments, predict crime hotspots, and generate comprehensive case reports with QR-linked virtual crime scene access.

---

## Key Features

### AI-Based Evidence Detection

* Detects and identifies forensic evidence from uploaded crime scene images.
* Powered by YOLOv8 and Computer Vision techniques.
* Automates evidence recognition and analysis.

### Crime Scene Reconstruction

* Generates immersive 3D crime scene visualizations.
* Interactive scene exploration using React Three Fiber and WebXR.
* Supports virtual investigation and evidence review.

### Evidence Mapping

* Maps detected evidence within reconstructed environments.
* Provides spatial context for forensic analysis.
* Enhances understanding of crime scene events.

### Crime Hotspot Prediction

* Utilizes Scikit-Learn machine learning models.
* Analyzes historical crime data to identify potential hotspot zones.
* Supports predictive policing and crime prevention strategies.

### Automated Case Reports

* Generates detailed PDF forensic reports.
* Includes evidence summaries and analysis results.
* QR-code integration allows direct access to VR crime scene visualization.

### REST API Integration

* Flask-based backend APIs for AI model processing.
* Seamless communication between frontend, backend, and machine learning modules.

## System Workflow

1. Upload crime scene images.
2. AI detects and classifies forensic evidence.
3. Evidence is mapped within a reconstructed 3D environment.
4. Machine learning models analyze crime patterns and hotspot regions.
5. System generates forensic reports.
6. Investigators access immersive VR crime scene visualization through QR codes.
